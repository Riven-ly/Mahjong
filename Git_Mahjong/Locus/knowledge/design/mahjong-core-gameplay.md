# mahjong-core-gameplay

## Summary
单机《羊了个羊》式主玩法设计与分层开发约束。

## Content
## 核心规则
- 卡牌按关卡配置进行多层固定堆叠，上层遮挡下层，仅完全无遮挡卡牌可操作。
- 玩法不再使用底部卡槽：玩家仅通过点击选择牌面卡牌。
- 首次点击会以卡牌自身独立的 SelectionEffect 标记选中；再次点击同一张牌会取消选中。HintEffect 仅由提示道具使用。
- 选中第二张牌时：同类型则两张牌均显示 SelectionEffect 后消除；不同类型时两张牌均保持 SelectionEffect、同时抖动，抖动完成后再同时取消选中状态并扣除 1 点生命。
- 每关初始 3 点生命；生命耗尽立即失败，牌面卡牌全部消除则胜利。
- 同类型消除时，第二张牌也显示 HintEffect 选中标记。先取两张牌当前位置的中点作为本次碰撞中心；该中心左右各偏移 300 得到两个中转点。两张牌分别移动到左右中转点（右侧牌对应右点），首次移动至卡牌边缘刚好接触的位置，随后向外回弹一次，再第二次接触；第二次触碰时在中点播放可池化的粒子特效并缩放消失。粒子独立完整播放与回收；卡牌缩放消失后立即完成消除结算、刷新剩余牌遮挡状态，并可接续下一组自动消除。
- 移除卡槽与拖拽交互；洗牌和提示仍保留。
- 关卡配置在运行时只作为牌位、层级与坐标来源，`typeId` 不参与实际牌面。所有有效关卡进入时统一随机生成两两配对牌型，绝不使用 JSON 中可能全为 typeId=1 的占位牌面。
- 任何关卡在运行时都不能因随机牌型/可解性问题抛异常。随机生成优先构造符合遮挡规则的成对可取顺序：每一步从当前同时无遮挡的牌中取两张，再沿该顺序连续按两张写入同一随机牌型（A,A,B,B）。若无法构造完整成对顺序，则保留牌位、随机打乱牌位索引并按两张写入同一随机牌型；不回退到单张可取顺序。运行时后台洗牌与返回道具自动消除共同兜底当前双选玩法的可操作配对。
- 运行时自动洗牌作为兜底保留：开局、手动洗牌及每次消除结算后检查当前可操作牌至少有一组同类型配对；如果不存在，保留全部未消除牌并在逻辑层后台洗牌，直到恢复一组可消除对，再一次性输出最终牌面。
- 返回道具改为自动消除 5 组：启动后每组选择当前可操作的同类型牌并使用正常碰撞、回弹、粒子消除表现；每组在 `CompleteEliminationAnimation` 完成后接续下一组。当前找不到可操作配对时，保留剩余牌并自动洗牌，直到出现下一组可操作配对。成功启动时扣除 1 个返回道具。

## 分层约束
- 单向依赖：Model → GameLogic → View。
- Model 为纯数据，不使用 Unity API。
- GameLogic 负责布局、遮挡、配对消除、生命耗尽失败和胜负。
- View 仅使用 UGUI，负责显示、动画和事件，不直接修改逻辑数据。
- 复用现有 UI 框架，主玩法集成到 GameScenePanel。
- MahjongCell 使用 Image + 数字占位，仅实现点击接口。

## 关卡配置
- 关卡目录使用单个 JSON 文件，按 `GameManager.Instance.playerInfo.level` 读取对应关卡。
- 每关仅配置标准整数网格行列，以及每张牌固定的类型、层级和坐标；偶数层的 `column`、`row` 必须在 `0..gridColumnCount-1` / `0..gridRowCount-1`，奇数层允许额外的左侧与底部扩展带，最小值为 `-1`。
- 分层布局采用羊了个羊式错位：偶数层保持整格，奇数层相对基础网格向右上横纵各偏移半格；高层卡牌与下层卡牌存在面积重叠时构成遮挡。
- 全局最大层数为10层，允许 Layer 0–9；堆叠层数、启用牌型和每种牌数量均从卡牌列表自动推导。
- 固定布局允许网格内留白和不连续轮廓，但整体保持紧凑；同类型牌应分散，避免同层相邻成对摆放。
- 关卡结构、边界、数量、重复位置和可解性全部只在编辑器生成或导入配置时校验；运行时只反序列化、按等级读取并创建卡牌，不执行任何关卡配置校验。
- 找不到玩家等级对应关卡时，从第11–321关的布局候选池随机选择一关；同一应用运行期间按玩家等级缓存该随机结果，失败重开和重新开局保持同一关，重启应用后允许重新随机。
- 匹配消除数量2为全局固定规则。
- 已重建 1–10 关：全部使用最大 4×4 网格的随机分散布局；牌数从 8 张逐关增加至 26 张，层数为第1–3关 3 层、第4–6关 4层、第7–9关 5层、第10关 6层。每个牌型通常仅配置 1 对，牌型从完整42种牌库中按关卡随机抽取；同类型牌不会在同层近位摆放。全部关卡已通过结构与求解器可解性校验，难度主要随层数和不同牌型数量上升。
- 已新增第11–20关的居中形状布局，包含中空方块、爱心、金字塔、菱形、双翼、沙漏、箭头、环形、螺旋与叠塔等轮廓；全部限制在4×4网格，使用3–4层与18–30张牌，并对每关随机牌型组合完成可解性校验。
