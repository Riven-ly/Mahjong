## 18:00-18:10 解包 abres.dat 逐环验证 + 兜底修复（ABResManager）

**结论：包内每一环都正确，粉紫不是"资源缺失"，是运行时 shader 变体未注册。**

**解包方法（可复用）**：`abres.dat` 是 AES-CBC( key `1234567890abcdef` / IV `abcdef1234567890` ) 加密的 UnityFS 包，
解密后是 `flags=0x243` 的 LZ4 包。**用 `UnityPy` 直接 load 解密后的字节流**即可（不要手写 UnityFS 解析，容易在 blockinfo 偏移上翻车）：

```python
from Crypto.Cipher import AES
import UnityPy
dec = AES.new(b'1234567890abcdef', AES.MODE_CBC, b'abcdef1234567890').decrypt(open('Assets/StreamingAssets/abres.dat','rb').read())
open('Temp/abres_dec/abres.assetbundle','wb').write(dec)
env = UnityPy.load('Temp/abres_dec/abres.assetbundle')
# env.objects -> obj.type.name / obj.read_typetree()
```
依赖：`pycryptodome`（已装）、`UnityPy` 1.25.4（已装）、`lz4`（已装）。
