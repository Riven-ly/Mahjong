### 规则表落地映射
| 操作 | Combo 变化 | 落点 |
|---|---|---|
| 成功消除一对 | +1 | `HandleCellSelectRequested` 成功分支 |
| 选中两张不匹配的牌 | 清零 | 同函数 `!result.Succeeded` 分支 |
| 再点已选中的牌，取消选择 | 不清零 | L274 `selectedCardId == cell.InstanceId` 分支，天然不处理 |
| 停下来思考、不操作 | 不清零 | 无超时逻辑，无需代码 |
| 手动使用洗牌 | 清零 | `TryShuffle()` 洗牌成功后 |
| 无可配对时自动洗牌 | 保留 | `EnsurePlayablePair()` 未动 |
| 开始新关卡 | 从 0 | `StartNewGame()` |
| 恢复已保存的同一局 | — | **用户决定暂不做**（本项目无牌局存档机制） |

### 关键设计判断
- **清零绝不能写进 `EnsurePlayablePair()`**：它被 `TryShuffle()`（手动，要清零）和 `CompleteEliminationAnimation`（自动，要保留）**双重调用**。清零放在 `TryShuffle()` 主体、洗牌成功之后。
- **自动消除（返回道具）天然不计入连击**：它走 `StartNextAutoElimination` → 直接 `PlayEliminationAnimation`，**不经过** `HandleCellSelectRequested`。把 `+1` 放在手动配对分支即可自动排除。
- **触发时机选「配对成功瞬间」**而非消除动画完成时（`CompleteEliminationAnimation`），反馈即时；`PlayCombo` 内部先 `Hide()` 再播，连击叠加无冲突。
- `DebugCompleteLevel()` 不走 `CompleteEliminationAnimation`，不受影响。

## 5. collectBtn 广告触发逻辑（otherAdBtn 方案 + 跨面板共享 adShownThisLevel）

用户在 GameWinPanel 和 GeneralRewardsPanel 的 prefab 上各加了一个 `RewardAdButton otherAdBtn`（位置/大小与 collectBtn 一致）。

**核心逻辑**：
- `otherAdBtn` 默认 `gameObject.SetActive(false)`（关闭，不拦截 collectBtn 点击）。
- 条件满足（`level > 2 && consecutiveNoAdCount >= 2`）时 `SetActive(true)` 打开，覆盖在 collectBtn 上拦截点击 → 走激励广告。
- GameWinPanel：条件满足时**必定**打开 otherAdBtn（激励广告 100%）。
- GeneralRewardsPanel：条件满足时**35%** 打开 otherAdBtn（激励视频），65% 不打开（走 collectBtn 插屏）。
- collectBtn 点击：`PlayBtnMusic() → OnClickInterstitialAd(page_id) → CollectClick()`（用户在 GeneralRewardsPanel 自行加了 `if (consecutiveNoAdCount >= 2)` 条件控制插屏）。
- `otherAdBtn.Init(CollectAdCallback, page_id, true)` —— 3 参数版（原版 RewardAdButton）。

**关键修复：adShownThisLevel 跨面板共享**
- 原问题：`adShownThisLevel` 是各面板实例私有字段，GeneralRewardsPanel 弹了激励广告后 GameWinPanel 不知道。
- 更大问题：GeneralRewardsPanel 单关可出现多次 → OnDisable 被调多次 → consecutiveNoAdCount 每关可能 +2+3。
- 修复：`adShownThisLevel` 移到 `PlayerInfo` 上，`[JsonIgnore]` 不持久化，两个面板共享同一变量。
  - GeneralRewardsPanel.OnDisable **不再递增** consecutiveNoAdCount，也不重置 adShownThisLevel。
  - GameWinPanel.OnDisable **唯一递增点**：`if (!adShownThisLevel && level > 2) → consecutiveNoAdCount++`，然后 `adShownThisLevel = false` 重置。
  - GameWinPanel.Refresh **不再重置** adShownThisLevel（重置时机改为 OnDisable 检查之后）。
  - 两面板的 AdsCallback / CollectAdCallback 设 `adShownThisLevel = true` + `consecutiveNoAdCount = 0`。

**改动文件**：
- `Assets/scripts/Manager/PlayerInfo.cs`：新增 `[JsonIgnore] public bool adShownThisLevel = false;`
- `Assets/scripts/Panel/GameWinPanel.cs`：移除私有 `adShownThisLevel`，改用 `playerInfo.adShownThisLevel`；OnDisable 末尾重置。
