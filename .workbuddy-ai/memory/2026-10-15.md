### 关键设计判断
- **清零绝不能写进 `EnsurePlayablePair()`**：它被 `TryShuffle()`（手动，要清零）和 `CompleteEliminationAnimation`（自动，要保留）**双重调用**。清零放在 `TryShuffle()` 主体、洗牌成功之后。
- **自动消除（返回道具）天然不计入连击**：它走 `StartNextAutoElimination` → 直接 `PlayEliminationAnimation`，**不经过** `HandleCellSelectRequested`。把 `+1` 放在手动配对分支即可自动排除。
- **触发时机选「配对成功瞬间」**而非消除动画完成时（`CompleteEliminationAnimation`），反馈即时；`PlayCombo` 内部先 `Hide()` 再播，连击叠加无冲突。
- `DebugCompleteLevel()` 不走 `CompleteEliminationAnimation`，不受影响。

## 11. 修正：依次弹出动画漏了「先全部隐藏」

**问题**：元素在 `Refresh` 时仍是 prefab 里的 active 状态，而 DOTween 的 `Sequence` 要到**下一帧 Update** 才执行第一个 `AppendCallback`。所以从面板 `SetActive(true)` 到序列起步之间，title / Items / 按钮会**正常显示一帧**，然后才被缩到 0 再弹出 → 肉眼看到「闪一下」。

**修正**（`GameWinPanel.cs`）：
- 新增 `HideShowTarget(RectTransform target, Vector3 targetScale)`：恢复原 scale + `SetActive(false)`
- `PlayShowAnimation()` 开头（建 Sequence **之前**）先对 title / itemRoot / rewardAdButton / collectBtn.parent 调 `HideShowTarget`，再建序列、播彩带、依次 `AppendShow`
- `ResetShowContent()`（OnDisable）重构为复用 `HideShowTarget`，消除重复代码

**验证**：`asset_refresh` 编译 `hasErrors:false / errorCount:0` ✅；`debug_get_errors` count=0 ✅

## 13. 卡牌入场动效（从 entrance.gif 逆向 → 落地）

**来源**：用户提供 `D:\Backup\Downloads\entrance.gif`（320×215，29 帧，80~90ms/帧，总 2.41s；**前 8 帧是动效，之后全是定格**）。

**逆向结论**（逐帧数值分析，非目视）：

- 画面 = 6×3 共 18 张麻将牌；动效 = **纯透明度淡入**，每张 alpha 0 → 1。
- **无缩放、无位移**：把每帧 alpha 除掉后量形状 bbox，alpha 0.138 / 0.304 / 0.813 / 1.0 时 bbox 恒为 46×58、中心不变 → 排除缩放。
  ⚠️ **坑**：用固定阈值直接量 bbox 会因低 alpha 下柔边/投影掉到阈值以下，假象成"缩小到 0.8"。必须做归一化形状量测。
- 顺序 = GIF 逐帧拟合是**行优先** `k = row*cols + col`（f01 第 0 行实测 alpha 0.274/0.207/0.134/0.067/0.018/0.0，与 `delay = c × 0.021s` 完全吻合）。**但用户要求改为「从左上角第一个向外扩散」**，故最终实现为**对角距离（Manhattan）扩散**，而非行优先。
  - 经验：GIF 的「行优先 + 小错峰 + 长淡入窗口」在视觉上就是一条斜向扩散带（同时有 ~16 张处于淡入中，跨 2.7 行），所以用户会描述成「扩散」。数值结论与用户感知不矛盾，但**以用户要求为准**。
- 参数：单张淡入 **0.33s**，相邻错峰 **≈0.021s**，18 张总时长 ≈0.7s。

**改动（2 个文件）**

- `Assets/scripts/Mahjong/View/MahjongCell.cs`
  - 新增 `AnimateEntrance(float duration, float delay)`：`canvasGroup.alpha = 0` → `DOFade(NormalAlpha, duration).SetDelay(delay).SetTarget(this)`
  - `MahjongViewConfig` 新增常量 `EntranceDuration = 0.33f` / `EntranceStagger = 0.021f`
- `Assets/scripts/Mahjong/View/MahjongGameplayView.cs`
  - `StartNewGame()` 末尾（`BuildBoardViews()` → `EnsurePlayablePair()` 之后）调用新增的 `PlayEntranceAnimation()`
  - `PlayEntranceAnimation()`：先求牌面**左上角原点**（`originX = min(x)`、`originY = max(y)`）→ 逐张按 `distance = |x-originX| / EntranceCellPitchX + |originY-y| / EntranceCellPitchY` 算对角距离 → `delay = distance * EntranceStagger` → `AnimateEntrance(duration, delay)`；动画期间 `SetBoardInput(false)`，`maxDelay + duration` 后 `DOVirtual.DelayedCall(...)` 恢复
  - 新增私有常量 `EntranceCellPitchX = BoardCellWidth * 0.5f`（81.5）、`EntranceCellPitchY = BoardCellHeight * 0.5f`（95）—— 即相邻牌的**实际**间距，保证「1 格 = 1 张相邻牌」
  - 不再需要排序（延迟由距离直接算出）

**顺序关键**：入场必须放在 `EnsurePlayablePair()` **之后** —— 它内部 `RefreshBoardStates()` → `SetBlocked()` 会把 `canvasGroup.alpha` 写回 1，放前面会被覆盖。
